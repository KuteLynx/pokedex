# 🔴 Pokédex

![Angular](https://img.shields.io/badge/Angular-21-DD0031?style=for-the-badge&logo=angular)
![TypeScript](https://img.shields.io/badge/TypeScript-5-3178C6?style=for-the-badge&logo=typescript)

Explorador de Pokémon construido con **Angular 21**. Consume la [PokéAPI](https://pokeapi.co/) para mostrar la lista completa de Pokémon con búsqueda, filtros y detalle con stats, tipos y sprites.

> 🧪 **Live demo**: [kutelynx.github.io/pokedex](https://kutelynx.github.io/pokedex/)
> 🎯 **Pokedex app**: [kutelynx.github.io/pokedex/pokedex](https://kutelynx.github.io/pokedex/pokedex/)

## 🎯 Features

- ✅ Lista completa de Pokémon con generaciones
- ✅ Búsqueda por nombre / tipo
- ✅ Filtros por tipo y generación
- ✅ Detalle individual con stats, habilidades, tipos y sprites
- ✅ UI dark mode responsive
- ✅ Lazy loading modules
- ✅ Signals para estado reactivo

## 🛠️ Development

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm start
# → http://localhost:4200

# Build
npm run build

# Tests
npm test
```
